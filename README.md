# Мой календарь — Android PWA

Минималистичный календарь с месячной сеткой, обзором двух недель и списком предстоящих записей.

## Возможности
- Месячный календарь с переходом между месяцами.
- Обзор двух недель.
- Список предстоящих записей по датам.
- Записи трёх типов: задача, гибкий план, событие со временем.
- Добавление, редактирование, удаление и отметка задач выполненными.
- Заметки к записям.
- Данные хранятся локально в `localStorage` этого браузера/установленного веб-приложения.
- PWA-манифест и service worker для установки и базовой работы офлайн.

## Как обновить проект на GitHub Pages
1. Распакуйте архив на компьютере.
2. Откройте свой репозиторий `moy-den` на GitHub.
3. Зайдите в папку репозитория, нажмите **Add file → Upload files**.
4. Перетащите файлы из папки `moy_kalendar` (`index.html`, `manifest.json`, `sw.js`, `icon.svg`, `README.md`) в корень репозитория. Не загружайте сам ZIP вместо файлов.
5. Нажмите **Commit changes**.
6. Откройте сайт GitHub Pages. Если старый экран ещё показывается, обновите страницу с очисткой кеша или подождите несколько минут. Service worker использует новую версию кеша `moy-kalendar-v1`.

## Как установить на Android
1. Откройте опубликованный GitHub Pages адрес в Chrome на Android.
2. Нажмите меню ⋮ → **Установить приложение** или **Добавить на главный экран**.
3. Откройте его с новой иконки.

## Важно про данные
- Записи сохраняются в локальном хранилище браузера на конкретном устройстве и в конкретном профиле браузера. Они не синхронизируются автоматически с компьютером и телефоном.
- Не очищайте данные сайта/браузера, иначе записи могут потеряться.
- При обновлении приложения на том же адресе обычно записи сохраняются, потому что ключ хранилища не меняется. Но перед крупными изменениями полезно предусмотреть экспорт резервной копии; в текущей версии экспорта пока нет.
- В календаре пока нет уведомлений. Даже браузерные push-уведомления требуют разрешения, поддержки браузера и часто серверной инфраструктуры; локальные уведомления и фоновые таймеры в веб-приложении не гарантируют срабатывание в заданное время, особенно когда приложение закрыто или система экономит батарею. Для надёжных системных напоминаний лучше использовать системный календарь Android или отдельное нативное приложение с разрешением на уведомления/точные будильники.
